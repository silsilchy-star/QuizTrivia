## 씨앗 원칙 — 주제별로 착각의 결이 다르다 (PLAN 6.3절)
- **지리**: "더 유명한 도시를 수도로 착각"이 압도적으로 강한 패턴이라 난이도 3의 절반 이상(오타와·캔버라·앙카라·브라질리아·베른·웰링턴·하노이·워싱턴 D.C....)을 이 패턴 하나로 채웠다. 나머지는 그린란드 왜곡 지도, 잉글랜드≠영국, 이집트는 아프리카 같은 지리적 착각.
- **스포츠**: "규칙 개정"이 가장 강한 패턴 — 배드민턴 21점(2006년 개정), 탁구 11점(2001년), 배구 25점 랠리포인트제, 축구 5명 교체(2022년), 월드컵 48개국(2026년), 야구 지명타자 통일(2022년). 옛 규칙으로 배운 세대가 많아 정답률이 확실히 떨어질 유형이다.

## 검증기 오탐 발견·수정
80문항을 채우고 나서야 발견됐다 — **주제 겹침 검사(6.4절 ⑤)가 항상 100%를 보고하고 있었다.** 좁은 태그는 정의상 넓은 태그의 부분집합이라, 작은 쪽 크기 기준으로 겹침을 재면 포함 관계 자체가 100%로 나온다. 같은 층위(`kind`)끼리만, 합집합 기준(자카드)으로 재도록 고쳐 오탐이 사라졌다. 검증기 로직이 실제로 여러 주제 데이터를 통과하기 전까지는 이 버그가 드러나지 않았다 — **첫 주제(과학) 하나만으로는 발견할 수 없는 종류의 결함**이었다.

## `NUMERIC_INPUT` 비율 맞추기 (PLAN 4.4절 20~25%)
생성 직후 세 주제 모두 목표를 벗어났다 — 지리 16%(부족), 스포츠 31%(초과). 문항을 새로 안 만들고 **기존 문항의 유형만 바꿔** 맞췄다:
- 스포츠: 이미 있는 사실(쿼터 수·라운드 수·선수 수 등)에 그럴듯한 오답을 붙여 6개를 MC로 전환 (31%→24%)
- 지리: 대양 개수(5)·날짜변경선 경도(180)·한국 광역자치단체 수(17)·유엔 회원국 수(193) 등 이미 검증 가능한 사실 4개를 NUMERIC으로 전환 (16%→21%)

전환 과정에서 문항 하나(`geo-113`)가 **내용은 날짜변경선으로 바뀌었는데 태그는 예전 그대로(`capital`) 남는 버그**가 있었다 — 발견 즉시 `timezone`으로 수정. 자동 변환 스크립트를 쓸 때 필드 일부만 바꾸면 이런 불일치가 생기기 쉽다는 걸 확인했다.

## 검증
```
문항 240개 — 승인 240 / 대기 0 / 반려 0
✅ active 과학 / 지리 / 스포츠 (난이도별 20/20/20/20)
⚠ 사람 검수 필요 22건 — 전부 최상급 표현, 전부 측정 기준 명시됨
NUMERIC_INPUT 비율: 과학 22.5% · 지리 21.2% · 스포츠 23.8% (전부 20~25% 안)
```

로컬 D1에 반영 후 세 주제 각각 1판씩 전부 정답 제출 → 난이도 합×10과 정확히 일치, `runId` 문법도 정상 (예: 스포츠 200점 = 여러 어려운 문항이 걸려 실제로 편차 발생 — 무작위 추출이 살아있다는 방증).
