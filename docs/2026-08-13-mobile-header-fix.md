# 모바일 폭에서 헤더 버튼 줄바꿈 수정

## 완료 판정
> "게임 점검 한 번 해볼래" 요청으로 실제 브라우저 클릭스루 점검을 하다 발견한 버그를 고쳤다.

## 무엇을 발견했나
랭킹 보드 작업(`e6d5a07`)에서 헤더에 "주제"/"랭킹" 네비게이션 버튼을 추가했는데, 390px·320px 같은 실제 모바일 폭에서 확인해보니 버튼 글자가 음절 단위로 줄바꿈됐다("주\n제", "랭\n킹"). `header`가 h1 + 네비게이션 2개 + 로그인 버튼을 한 줄에 욱여넣도록 되어 있어 좁은 화면에서 공간이 부족했던 것.

## 무엇을 고쳤나
- `header`에 `flex-wrap: wrap` — 공간이 부족하면 버튼 묶음째로 다음 줄로 내려간다.
- `button.ghost`에 `white-space: nowrap` — 개별 버튼 텍스트 자체는 절대 음절 단위로 안 쪼개지게 한다.

## 검증
Playwright로 390px·320px(아이폰 SE 폭) 스크린샷을 찍어 확인. 수정 전엔 "주 / 제"처럼 깨졌고, 수정 후엔 버튼이 통째로 다음 줄로 내려가며 텍스트는 깨지지 않았다.
