# 로그인 직후 랭킹 캐시가 갱신되지 않던 문제

## 완료 판정
> 사용자 보고 "랭킹 페이지에 점수 기록 안 되는데" — 원인을 찾아 고쳤다.

## 무엇을 발견했나
`ranking_cache`(통합 2개 보드)는 판이 끝날 때(`finalizeRun`)만 다시 계산되도록 짜여 있었다. 그런데 계정이 랭킹 집계 대상이 되는 시점(`is_anonymous 1 → 0`)은 **로그인 콜백**이지 판이 끝나는 시점이 아니다. 그래서 익명으로 쌓아둔 최고 기록이 있는 상태로 로그인만 하면, 다음 판을 한 번 더 끝내기 전까지는 캐시가 그 사람을 반영하지 못한 채로 남아 있었다.

## 무엇을 고쳤나
`worker/auth.ts`의 `handleAuthGoogleCallback`에서 계정 연결(`linked`)/전환(`switched`) 처리 직후 `refreshGlobalCaches`를 바로 호출하도록 추가했다.

## 검증
코드 경로 검토와 프로덕션 OAuth 시작/콜백 흐름 확인(실제 client_id로 정상 리다이렉트)까지는 확인했으나, 실제 계정으로 "익명 플레이 → 로그인 → 즉시 랭킹 반영"을 처음부터 끝까지 재현 검증하지는 못했다 — 로컬에서는 실제 구글 로그인을 완주할 수 없기 때문.

## 후속으로 밝혀진 사실
이 수정 직후 사용자가 실제로 랭킹에 점수가 하나도 안 뜨는 걸 다시 보고했고, 서버의 `topic_best`(캐시 아닌 실시간 조회)를 직접 조회해보니 **세 주제 전부 승인된 판이 0개**였다. 즉 이번 건과는 별개로 (a) 판을 스테이지 중간에 멈추고 끝까지 안 갔거나, (b) 아래 `2026-08-13-critical-schema-drop-fix.md`에 적은 배포마다 테이블이 지워지던 버그 때문에 이미 있던 기록이 지워졌을 가능성이 있다.
