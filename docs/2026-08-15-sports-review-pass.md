# sports 320문항 검수 — 유사 중복 4건 적발·수정

`npm run review`는 브라우저로 여는 검수 페이지라 이 작업 환경에서는 열 수 없다. 대신 **기계가 놓치는 종류**를 직접 훑었다.

## 왜 이 검사인가

`validate`의 중복 검사는 문구를 정규화해 **완전히 같은지**만 본다. 그래서 어순과 동의어를 넘지 못한다 — 실제로 오늘 "월드컵 본선 48개국" 문항이 두 벌 들어갔다가 뒤늦게 발견됐다(`2026-08-15-olympics-questions.md`).

그래서 **어절 단위 자카드 유사도**로 400문항을 전부 짝지어 훑고, 특히 **정답까지 같은 쌍**을 골라냈다. 정답이 다르면 문형이 닮아도 정상적인 병렬 문항이기 때문이다(버디/보기/알바트로스, 2위 은/3위 동).

## 잡아낸 것

| 쌍 | 문제 | 조치 |
|---|---|---|
| `spo-200` ≡ `spo-203` | **완전 중복.** 둘 다 "마라톤 정식 거리, 소수점 버림 → 42" | 계주 구간 거리(100m) 문항으로 교체 |
| `spo-429` ≡ `spo-210` | 정답이 둘 다 "해트트릭". 축구/아이스하키로 종목만 다르고 묻는 용어가 같음 | 파워플레이 문항으로 교체 |
| `spo-157` ≡ `spo-109` | 둘 다 olympics 태그 · "아닌 것은?" 형태 · 정답 "역도" | 레슬링 문항으로 교체 |
| `spo-149` ≡ `spo-103` | 정답이 둘 다 "4". "월드컵은 몇 년마다"와 "올림픽은 몇 년마다" — 하나를 알면 둘 다 풀림 | 경기장 안 총 선수 수(22명) 문항으로 교체 |

넷 다 **내가 오늘 넣은 문항** 쪽을 고쳤다.

검사 결과 **정답이 같으면서 문형이 35% 이상 겹치는 쌍은 0건**이 됐다.

## 남겨 둔 것 (정상으로 판단)

- 골프 버디/보기/알바트로스, 올림픽 2위 은/3위 동, 농구 5명/배구 6명, 1896/1924 — 문형은 닮았지만 **서로 다른 사실**을 묻고 정답도 다르다. 오히려 짝을 이뤄 배우기 좋다.
- 같은 숫자 정답이 여러 번 쓰인 것("3" ×10 등) — 각각 별개의 사실이라 문제 삼지 않았다.

## 아직 남은 한계

**사실 확인은 못 했다.** 난이도 3의 규칙 개정 연도와 수치(탁구공 40mm, FIBA 3점 라인 6.75m, 배드민턴 서브 1.15m 등)는 `seedRef`를 달아 뒀지만, **이 작업 환경은 외부 사이트가 프록시로 막혀 있어 그 문서를 직접 열어보지 못했다.** 사람 검수에서 이 부분을 봐야 한다.
